# Баялгийн толь · Mongolia Resource Mirror

Монголын байгалийн баялаг хилээр гарахдаа хэр хэмжээгээр, ямар үнээр бүртгэгдэж, хүлээн авагч улсад хэрхэн бүртгэгдэж байгааг тулгаж харьцуулдаг нээлттэй систем.

*Open-data mirror of Mongolia's natural resource exports: what leaves the country, where it goes, and who gets paid. It compares what Mongolia reports exporting with what its trading partners report importing ("mirror trade statistics"), to surface gaps that deserve questions.*

## Хэрхэн ажилладаг вэ · How it works

1. **Өгөгдөл татах** — `scripts/fetch_comtrade.py` НҮБ-ын Comtrade сангаас Монголын экспорт болон түнш улсын импортын мэдүүлгийг татна. Одоогоор: нүүрс, зэс, ноос-ноолуур, жонш (Хятад), алт (Швейцарь, Өмнөд Солонгос), ноос-ноолуур (Итали).
2. **Тулгах** — `scripts/analyze.py` хоёр мэдүүлгийг харьцуулж, зөрүүг тэмдэглэнэ.
3. **Харуулах** — `docs/index.html` самбар GitHub Pages дээр нийтэд харагдана.
4. **Автомат шинэчлэлт** — GitHub Actions сар бүрийн 5-нд өөрөө ажиллана.

## Тэмдгүүд · Flags

| Тэмдэг | Утга |
|---|---|
| Үнийн дүн зөрүүтэй | Хоёр улсын бүртгэл 5%-аас их зөрсөн |
| Хятад бага бүртгэсэн | Импортлогч экспортлогчоос бага бүртгэсэн — ердийн үед эсрэгээрээ байдаг |
| Тонн зөрүүтэй | Жин 10%-аас их зөрсөн |
| Тонн тутмын үнэ зөрүүтэй | Нэгжийн үнэ 10%-аас их зөрсөн |
| Жин тооцоолсон | Нэг талын жин хэмжсэн биш, тооцоолсон тоо |
| ... илгээгээгүй | Тухайн улс энэ хугацааны өгөгдлөө НҮБ-д илгээгээгүй |
| ... огт бүртгээгүй | Түнш улс Монголтой худалдаагаа мэдүүлсэн боловч энэ барааг огт бүртгээгүй |

**Тэмдэг бол буруутгал биш — тайлбар шаардах асуулт.** Хэвийн зөрүүний шалтгаан: оны заагаар бүртгэл шилжих, тээврийн зардал (CIF/FOB), нойтон ба хуурай тонн, ангиллын ялгаа.

## Уурхайн гарцын бүртгэл · Mine-output registry (туршилтын хувилбар)

Экспортын статистик зөвхөн "нүүрс", "зэсийн баяжмал" гэж харуулдаг. Харин уурхайгаас гарч буй багц бүрийн **дотор юу байгааг** (зэс, алт, мөнгө, молибден, цайр, газрын ховор элемент...) хэмжиж, компанийн мэдүүлэгтэй тулгах нь энэ хэсгийн зорилго.

1. **Хэмжих** — конвейер дээрх анализатор (PGNAA, LIBS), гар XRF эсвэл лаборатори багц бүрийн найрлагыг хэмжинэ. Хэн хэмжсэнийг (компани, хараат бус, гааль) тэмдэглэнэ → `data/mine/measurements.csv`
2. **Мэдүүлэг** — компани багц бүрт юу мэдүүлснийг → `data/mine/declarations.csv`
3. **Түгжих** — `scripts/mine_ledger.py` мөр бүрийг SHA-256 гинжин бүртгэлд (`data/mine/ledger.jsonl`) нэг удаа бичнэ. Хуучин бичилтийг өөрчилбөл гинж тасарч, шууд илэрнэ.
4. **Тулгах** — хэмжилтийг мэдүүлэгтэй харьцуулж, `docs/mine.html` самбарт харуулна.

```
python scripts/mine_ledger.py          # ingest + verify + analyze
python -m unittest discover -s tests   # шалгалт
```

| Тэмдэг | Утга |
|---|---|
| Мэдүүлээгүй элемент | Хэмжилтээр мэдүүлэх босгоос дээш агууламж илэрсэн боловч мэдүүлээгүй |
| Агууламжийг бага мэдүүлсэн | Мэдүүлсэн агууламж хэмжсэнээс 10%-аас их бага |
| Компани ба хараат бус хэмжилт зөрсөн | Хоёр хэмжилт 10%-аас их зөрсөн |
| Тонн зөрүүтэй | Мэдүүлсэн тонн жинлэснээс 3%-аас их зөрсөн |
| Хараат бус дээжгүй | Зөвхөн компани өөрөө хэмжсэн |
| Бүртгэлийн дараа засварласан | Түгжигдсэн мөрийг эх файлд өөрчилсөн (бүртгэл анхны утгыг хадгална) |

Босго, элементүүдийг `scripts/mine_config.py` дотор өөрчилнө. **Одоогийн өгөгдөл бүхэлдээ зохиосон жишээ** — бодит уурхай, компанийг илэрхийлэхгүй.

## Тохируулах · Setup

Энэ системийг өөрөө ажиллуулахыг хүсвэл info@mcbis.org хаягаар холбогдоно уу.

## Бүтээгдэхүүн нэмэх · Adding commodities

`scripts/config.py` дотор `COMMODITIES`-д HS код, `PAIRS`-д түнш улс нэмнэ. Жишээ нь: `"2601"` төмрийн хүдэр, `"2608"` цайрын баяжмал.
